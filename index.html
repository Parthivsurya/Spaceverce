Pool your Google accounts into one drive.

Gstore links the accounts you already own and presents their free space as a single store on your desktop.

Download View source

How it works

  1. 1

    Link your accounts

    Sign in to each Google account you own and want to use. Two or more is where this starts to pay off.

  2. 2

    Gstore reads each quota

    It asks Google how much space every linked account has and how much is still free, then adds them up.

  3. 3

    Uploads spread out

    New files go to an account with room. A file too big for any single account is split into chunks across several.

Windows

64-bit Windows 10 and 11. There is no 32-bit build, and no installer: you unzip it and run it.

  • Gstore-0.0.2-windows-x64.zip 64-bit Windows

Every link above opens the latest release on GitHub, where these files are attached. The version in each filename changes with each release. You will also need the Google accounts you want to pool; Gstore does not create accounts for you.

First launch

Neither build is signed with a paid Apple or Microsoft developer certificate, so both systems will warn you the first time you open Gstore. The source is public instead, so anyone can read what goes into a build. Here is what you will see, and what to do about it.

macOS

  1. Open the .dmg and drag Gstore into Applications.
  2. Open it. macOS blocks the first launch and says it cannot check the app for malicious software.
  3. Go to System Settings, then Privacy & Security. Scroll to the notice about Gstore and click Open Anyway.
  4. Gstore then asks for your login keychain password once, so it can store its encryption key there. Choose Always Allow and it stops asking.

Recent macOS versions removed the old right-click, then Open shortcut. The Privacy & Security panel is now the way through.

Windows

  1. Unzip the folder, then keep it in one piece.
  2. Run Gstore.exe from inside that folder. It needs the files next to it, so it is not a single portable exe you can move on its own.
  3. SmartScreen says "Windows protected your PC". Choose More info, then Run anyway.

Put the unzipped folder somewhere permanent before you make a shortcut to it.
